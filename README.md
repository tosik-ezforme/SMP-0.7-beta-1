# LegendaryWeapons (Spigot 1.21.11, Java 21)

Легендарное оружие, алтари создания и медный комплект брони для SMP.

## Сборка
    mvn package
Готовый плагин: `target/LegendaryWeapons.jar` → в папку `plugins/` сервера Spigot 1.21.11. Нужна Java 21.
SQLite-драйвер входит в состав Spigot, отдельно ничего ставить не нужно. Данные: `plugins/LegendaryWeapons/data.db`.

## Управление
- **Shift + ПКМ** — первая способность.
- **F** — вторая способность (открывается после 5 убийств 5 разных игроков этим оружием).
- **Shift + F** с полным медным комплектом (без легендарки в руке) — «Гальванический разряд».

## Команды (права `legendary.command.*`, всё сразу — `legendary.admin`)
| Команда | Что делает |
|---|---|
| `/legendary give <игрок> <id> [кол-во]` | выдать оружие, `copper_set`/часть брони, `food_bucket` или компонент (`mace_head`, `dagger_base`) |
| `/legendary reload` | перечитать config.yml и рецепты |
| `/legendary info <игрок>` | сердца, заряды, прогресс по оружию |
| `/legendary progress <игрок> <оружие> get/set [n]` | просмотр/правка прогресса |
| `/legendary hearts <игрок> set/add/remove <n>` | постоянные сердца |
| `/legendary altar create <тип>` | зарегистрировать уже построенный алтарь (курсор на центр) |
| `/legendary altar build <тип>` | построить и зарегистрировать алтарь (курсор на землю) |
| `/legendary altar remove / validate / cancel` | удалить из реестра / проверить / отменить ритуал (курсор на центр) |
| `/legendary altar list` | список алтарей |
| `/legendary banlog [игрок]`, `/legendary unban <ник>` | журнал Молота бана и разбан |
| `/legendary unique list / reset <оружие>` | состояние уникальных предметов |
| `/legendary cooldown list` | все перезарядки |
| `/legendary cooldown <id> <primary/secondary/both> <сек>` | сменить перезарядку способности (пишется в config.yml) |
| `/legendary cooldown reset <игрок>` | сбросить активные перезарядки игрока |

Тип алтаря = id оружия: life_stealer, light_blade, ender_blade, ban_hammer, thunderer, tecton, inferno, frost_axe, crusher, blood_oath, phantom, prisoner.
Все админ-действия пишутся в таблицу `admin_log`.

## Защита от дюпа
Подлинность предмета определяется только по PersistentDataContainer. У каждого экземпляра свой instance-ID:
вторая копия удаляется у игрока (проверка инвентаря и эндер-сундука раз в 5 с), материалы ритуала резервируются в БД,
награда выдаётся ровно один раз, ритуалы переживают рестарт. Ограничение: копии, лежащие в сундуках или на земле,
ловятся, когда игрок их забирает.

## Обновление 2
- **Алтари**: `/legendary altar build <тип>` строит большой цветной алтарь (площадка 15x15, 8 колонн до 12 блоков, светящееся кольцо, радиус `altars.radius`). Постройка очищает воздух вокруг.
- **Главный блок** алтаря нельзя сломать никому (в том числе поршнями, взрывами, существами); убрать алтарь можно командой `altar remove`. Работоспособность алтаря зависит только от главного блока.
- **Ритуал** у всех оружий 15 минут (`crafting.ritual.*`). Оружие в конце **выпадает на главный блок** алтаря (не исчезает, не горит). Для надёжности запись о награде хранится в БД до момента выпадения.
- **Координаты в чате**: стадии 0/25/50/75/90% времени. Сначала цифры закрыты `▒`, потом открываются слева направо, на последней стадии видны полностью; каждому игроку показывается расстояние и сторона света.
- **Характеристики**: оружие как незеритовое (меч/кинжал 8 урона, топор 10, булава и копьё 8), броня как незеритовая (3/8/6/3, твёрдость 3, стойкость 0.1). Только для новых предметов.
- **Босс-бар** с перезарядкой обеих способностей при оружии в руке (в полном комплекте показывает «Разряд»). Выключается: `bossbar.enabled: false`.
- **Булава**: ванильный рецепт убран (`general.disable_mace_craft`), сама булава и компоненты остались.
- **Ведро еды** (`food_bucket`): 2 порции, насыщение как у золотой моркови, золотое сердце, перезарядка 30 с. Крафт на верстаке: золотая морковь x32, золотой слиток x10, ведро молока, зачарованное золотое яблоко x2 — каждый ингредиент в своей клетке стеком нужного размера, без Shift.
- **Багровый Обет**: первая способность называется «Жажда крови», вторая — «Полёт нетопырей» (взлёт по направлению взгляда на 3.5 с в стае летучих мышей, пока летишь — неуязвим).

## Обновление: что нового
- Ритуал: координаты открываются по одной (X через 4 мин, Y, Z), без расстояния и процентов; таймер голограммой над столом алтаря.
- Легендарки всегда подсвечены, не уничтожаются (только пустота), одна на карту (`unique: true`); менять/дюпать может только админ.
- Ведро еды: бесконечное, перезарядка 30 с, снимает негативные эффекты (кроме эффектов легендарок). Рецепт в `food_bucket.recipe`.
- Алтари +20% (`altars.scale`), тематическое убранство. Тектон → «Страж Глубин» (Варден).
- Команды: `/legendary altar spawn <тип> [x z] [мир]`, `/legendary altar random [тип|all]`, `/legendary altar tp <id>`, `/legendary menu`, `/legendary give <ник> admin_menu` (предмет «Звезда управления»).
- Иконки: распакованный пак в `resource_pack/`, zip отдельно. Залейте zip на хостинг, впишите `resource_pack.url` и `sha1`, затем `enabled: true`.
- Перед запуском удалите старый `plugins/LegendaryWeapons/config.yml`. Старые алтари перестройте командой `altar build`/`spawn`.

## Табло статистики
Справа на экране у каждого игрока висит табло: убийства, смерти, время выживания (с последней смерти) и сердца.
`/stats` (доступна всем) — включить/выключить для себя. Настройки: `stats_board.*` в config.yml.
Табло — это собственный scoreboard игрока, поэтому цвета команд (teams) в табе и над головой у таких игроков не отображаются.
Если нужны ваши команды — выключите `stats_board.enabled`.

## Данжи «Проклятый замок»
Редкая локация: крепостная стена с зубцами, 4 угловые башни, привратная башня, двор с колодцем и кузней,
донжон с тронным залом и склеп с клетками, спавнерами и боссом «Рыцарь-страж склепа».
В сундуках лежат компоненты для крафта (пластина, навершие булавы, голова топора, основа кинжала) и обычная добыча.
Сундуки и босс обновляются раз в `dungeon.refill_minutes`.

- `/legendary dungeon spawn [x z] [мир]` — построить в точке (без координат — под вами)
- `/legendary dungeon random [кол-во]` — случайно расставить по карте
- `/legendary dungeon list | tp <id> | refill <id> | remove <id>`
- Меню админа → Инструменты: кнопки «Данж под вами», «Случайные данжи», «Обновить все данжи»
- Право: `legendary.command.dungeon` (у `legendary.admin` есть по умолчанию)
`remove` только убирает данж из списка — постройку в мире снесите через WorldEdit.
